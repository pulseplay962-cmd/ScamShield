# ScamShield

**Before You Click, Check.**

ScamShield is a privacy-first second-opinion tool for suspicious emails, text messages, screenshots, and links.

## V1 goals

- Explain why content may be suspicious
- Use clear risk levels instead of unexplained verdicts
- Give practical next steps
- Minimize retention of sensitive content
- Keep the product independent from PulsePlay

## Planned stack

- React + TypeScript + Vite
- Node.js + Express
- Supabase / PostgreSQL
- OpenAI API
- Render
